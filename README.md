# Proyecto Final Interfaces y Periféricos - UCO

Este repositorio contiene el proyecto final de **Interfaces y Periféricos** del grado en Ingeniería Informática en la especialidad de Computadores de la **Universidad de Córdoba (UCO)**.

## Descripción

Implementación de un juego haciendo uso de Arduinos y un sistema de leds para descifrar una contraseña.


## Tecnologías y herramientas

- Lenguaje: **C++**
- Plataforma: TinkerCad
